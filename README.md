# OSINT Agent — Поиск и сбор информации из открытых источников

Универсальный инструмент для сбора данных о чём угодно: компании, интернет-магазины, пансионаты, кафе, отели, рестораны, места, бренды, личности. Работает через DuckDuckGo, 2GIS, Яндекс.Карты и веб-скрапинг. Не требует API-ключей.

## Возможности

| Модуль | Что собирает |
|--------|-------------|
| **DuckDuckGo** | Ссылки, заголовки, сниппеты |
| **2GIS** | Адрес, рейтинг, телефоны, соцсети |
| **Яндекс.Карты** | Адрес, телефоны, часы работы, рейтинг |
| **Веб-скрапинг** | Телефоны, email, соцсети с сайта |
| **Поиск соцсетей** | Instagram, Telegram, VK, TikTok, Facebook, YouTube, WhatsApp |

## Быстрый старт

```bash
# 1. Установка зависимостей
pip install -r osint_agent/requirements.txt

# 2. Запуск сбора
python osint_agent/osint_agent.py "Что ищем"
```

## Примеры

```bash
python osint_agent/osint_agent.py "Шоколадница"         # Сеть кофеен
python osint_agent/osint_agent.py "Raduga West"         # Пансионат
python osint_agent/osint_agent.py "Яндекс"              # IT-компания
python osint_agent/osint_agent.py "Wildberries"         # Интернет-магазин
python osint_agent/osint_agent.py "Отель Украина"       # Гостиница
python osint_agent/osint_agent.py "Ресторан Венеция"    # Ресторан
```

После выполнения в папке `osint_agent/results/` появятся:
- `report_ИМЯ_20260617_1730.md` — читабельный отчёт
- `report_ИМЯ_20260617_1730_raw.json` — сырые данные

## Почему DuckDuckGo, а не Google?

Раньше использовался Google Custom Search API — он требует привязки карты, платный после 100 запросов/день, и не ищет по всему интернету (тумблер "Поиск во всём интернете" серый для новых пользователей). DuckDuckGo полностью бесплатен, без ограничений и ключей, не хуже по качеству для русскоязычных запросов.

## Легальность

Инструмент использует **только открытые источники** (OSINT).
Не используйте для незаконной деятельности.
